I found a <a href="http://wordpress.org/extend/plugins/table-of-contents-plus/">nice plugin</a> for <a href="http://dublue.com/plugins/toc/">adding a table of contents to a post</a> (like the wiki pages have)

However it had one limitation, there is no back to top link. Since we want to go back to the toc (which can be at the top / bottom), Ive called it the back_to_toc feature.

It has 3 options - not to show / show text / show image.

See snippets overleaf or <a href="http://cselian.com/d/code/?folder=YXBwcy93cC10b2M=">explore the  code</a> (line 559 of <a href="http://cselian.com/d/code/serve.php?file=./apps/wp-toc/toc.php">toc.php</a> is where the real changes start). Or <a href="http://mini.cselian.com/info/ozone/medical-use">view it in action</a>.
<!--more-->

[tab: code]

The plugin filters the <strong>the_content</strong> method and the code added to it is

toc.php
<pre class="brush: php">//Line 560
$btt = "";
if ($this-&gt;options['back_to_toc'] != TOC_BACKTOTOC_NONE)
{
	$img = $this-&gt;options['back_to_toc'] == TOC_BACKTOTOC_IMG;
	$bttText = $img ? " " : "top"; //space else image doesnt show
	$bttSuffix = $img ? "_img" : "";
	$btt = '<a class="toc_to_top' . $bttSuffix . '" href="#toc_start">' . $bttText . '</a>';
}

//Line 617
if ($this-&gt;options['back_to_toc'] != TOC_BACKTOTOC_NONE)
	$html = '<a name="toc_start"></a>' . $html;</pre>
