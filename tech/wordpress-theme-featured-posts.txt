I'm modifying the <a href="http://wordpress.org/extend/plugins/wp-featured-post-with-thumbnail/">wordpress plugin</a> to include a custom Ordering and expose a method cs_get_featured_posts which wraps query_posts for use directly in a theme. I need this for letting the theme customize the results instead of simply using the widget provided in the original. <a href="http://cselian.com/d/code/?folder=YXBwcy9mZWF0LXBvc3Rz">Browse source</a>.

<pre class="brush: php">function cs_get_featured_posts()
{
	//add filters for posts_join_paged, posts_where_paged, posts_orderby
	query_posts('posts_per_page=10&amp;showposts=10');
	//remove filters
}
function featposts_join_sql( $meta_sql )
{
    return " LEFT JOIN wp_postmeta as pmF ON (wp_posts.ID = pmF.post_id AND pmF.meta_key = 'featured') "
    		.= " LEFT JOIN wp_postmeta as pmO ON (wp_posts.ID = pmO.post_id AND pmO.meta_key = 'featuredOrder') ";
}
function featposts_where_sql( $meta_sql )
{
    return " AND (pmF.meta_value = 1)";
}
function featposts_order_sql( $orderby )
{
    return 'pmO.meta_value ASC';
}</pre>
