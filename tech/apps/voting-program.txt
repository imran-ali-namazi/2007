[tab: Intro]

For counting votes (admin only), this simple program (written in 45 minutes) shows a set of buttons for each candidate and you can click on the button to increase his votes.

Candidates.txt is the input and also where the count is stored.
Once counting is over (or anytime), simply open the Count tab to see the results.

Count has 3 buttons. Clear to reset all counts to 0, Names to open the text file for editing, Reload when changes are made manually.

See code overleaf or <a href="http://cselian.com/d/code/?folder=cHAvNQ==">browse</a> or <a href="http://cselian.com/d/code/pp/5/Voting.zip">download</a>.

Approach:
<ul>
	<li>Create a Candidate Control which has a button to show his name and a label to display the number of votes. have it implement ICandidate for <a href="http://en.wikipedia.org/wiki/Separation_of_concerns">SoC</a></li>
	<li>ICandidate has PersonName, Votes (int) and a Clear() method.</li>
	<li>VoteForm loads from file and puts controls in a flow panel.</li>
	<li>Candidate Control broadcasts a static event whenever a vote is made. this is listened in the Form and the text file is saved each time.</li>
</ul>
